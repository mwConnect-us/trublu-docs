# TruBlu HVAC Reference Site

Hosted via GitHub Pages at: **https://mwconnect-us.github.io/trublu/**

This is a TruBlu™/mwConnect-branded mirror of the NetX 240273 X-Series installation manual, annotated for the technical writing team to guide porting the content to mwConnect.us.

## Setup GitHub Pages

1. Go to: `https://github.com/mwConnect-us/trublu/settings/pages`
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/docs`
4. Save — the site will be live in ~2 minutes.

## Annotation Color Key

| Color | Meaning |
|---|---|
| Green | Preserve content as-is |
| Orange | Rewrite / rebrand for mwConnect |
| Blue | New TruBlu content to add |
| Purple | Pending engineering or product input |
